01 — Why Celarix

Depth without the clutter

Most clients are either a single gimmick or a maze of nested menus. Celarix is a full toolkit with a flat, predictable surface: one key, seven windows, every switch exactly where you left it.

Everything behind one key

Press Left Alt and the whole client is there — draggable windows, live sliders, toggles that re-pack instead of stacking on top of each other.

Built to stay out of the way

Hacks reset when you join or leave a server, Panic kills everything at once, and the performance modules tune settings the game already has rather than fighting the renderer.

Kept current

Seven releases of steady work: render-pipeline fixes, a fly rewrite, projectile ballistics, autonomous tunnelling — and a fresh batch of eleven modules in v1.0.7.

05 — Changelog

Seven releases, one direction

v1.0.0 shipped for 1.20.4. Every release since has landed on 1.21.5 — fixes first, then new capability.

v1.0.7current · 1.21.5

Utility batch. Eleven new modules — Restock, Auto Shear, Auto Tame, Bonemeal, Till Aura, Bunker, Auto Bucket, Radar, Derp, Anti Spam and Multi Task (attack while you eat).

v1.0.61.21.5

Autonomy. Tunneller digs cardinal 1×2 tunnels; Fight Bot seeks and melees whatever the aim system has locked.

Ballistics & mining. Bow Aimbot with a real arrow-arc solver, Vein Miner with reach-aware traversal, and a clean No Fog pass.

Extras. Zoom, Free Cam and Inventory Walk — and a startup crash fix in ESP.

v1.0.01.20.4

Initial release. Survival flight, ESP with tracers, aimbot, speed, and the survival autopilot that mines, shelters, loots and fights on its own.

06 — Install

Running in about two minutes

Three steps, the same for both builds. Match the versions and you're done.

STEP 01

Install Fabric

Run the Fabric installer for your game version — loader 0.15+ for 1.20.4, 0.16+ for 1.21.5.

STEP 02

Add Fabric API

Grab Fabric API for the same Minecraft version and drop it into mods. It's a hard dependency.

STEP 03

Drop in Celarix

Put the matching Celarix jar in mods as well, launch the game, and press Left Alt in a world.

Use it where it's welcome. Celarix is client-side: at home in single player and on servers that allow utility clients, and against the rules on servers that don't.
07 — FAQ

Answers, quickly

Which download do I need?

Match your game version. Minecraft 1.21.5 takes the v1.0.7 jar; 1.20.4 takes the v1.0.0 jar. They include the same Click GUI and the same core toolkit — the 1.21.5 build simply carries everything added since. The legacy jar also loads across the 1.20.x line, but 1.21.5 is the only version the modern build targets.

The game won't start — what happened?

Nine times out of ten it's two Celarix jars in mods. They share the mod id, so Fabric stops with a duplicate-mod error. Keep exactly one, and make sure Fabric API matches your game version.

Do I need Fabric API?

Yes — Celarix is built on it and declares it as a dependency. Download the Fabric API build for your Minecraft version before launching.

How do I verify a download?

Open the SHA-256 checksum disclosure on either download card — each one has a copy button. Compare it with your saved file using Get-FileHash file.jar -Algorithm SHA256 in PowerShell, or sha256sum file.jar anywhere else. The checksums on this page were generated from the files in this folder.

How do I turn everything off in a hurry?

Panic in the Client window switches every module off at once. Hacks also reset themselves when you join or leave a server, so each session starts clean with only the HUD modules you chose. The reset list is intentionally short: ESP, Tracers, Invis Reveal, Crosshair, Fullbright and Friends.

Does it work on servers?

It runs client-side, so it connects like any Fabric client. Whether it's allowed is entirely up to the server you're on — plenty of anarchy and private servers are fine with utility clients, and plenty of others will ban you for it. Read the rules first.
